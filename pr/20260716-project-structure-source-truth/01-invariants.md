# Invariants

1. `src/bin` is for thin process entry points and maintainer verification
   binaries only; reusable runtime logic stays in library modules.
2. SDK conformance execution belongs under `tools/sdk-conformance-runner`, not
   `src/bin`.
3. `provider_routes` is an explicit source root because generated route
   constants and SDK tests consume its manifests.
4. System AbilityDescriptor TOMLs must be grouped by capability domain;
   federation is one of those domains.
5. Generated bytecode directories such as `__pycache__` are not source and must
   be absent when running the project-structure gate.
