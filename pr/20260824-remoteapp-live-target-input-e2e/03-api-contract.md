# API contract

No production Ability or Invocation shape changes.

The bundled host receiver gains an opt-in input-proof mode configured by host
test environment variables. When enabled it creates the canonical WebRTC input
data channel before creating the SDP offer, obtains the current session input
policy after negotiation, and sends one bounded pointer interaction and one
bounded keyboard interaction carrying the committed geometry/focus epochs.

The receiver writes a machine-readable input transmission artifact containing
the exact frames, channel-open evidence, transport epoch, and session view used
for epoch selection. The AppKit fixture exports selected/unrelated event-log
paths. The host runner joins these artifacts with daemon session events into
the existing input-injection evidence contract.
