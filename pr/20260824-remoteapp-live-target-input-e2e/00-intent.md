# Intent

Close the remaining macOS RemoteApp target-local input proof gap with a real
host execution loop: a public CLI-created interactive session, the production
WebRTC input data channel, daemon-side target guarding and CGEvent injection,
and an independent AppKit target that records the resulting mouse and keyboard
events.

This work produces executable evidence. It does not turn synthetic verifier
fixtures into a product-completion claim, and it does not claim Windows/Linux
target-local input support.
