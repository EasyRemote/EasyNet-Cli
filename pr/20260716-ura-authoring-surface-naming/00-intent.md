# URA authoring surface naming

## Intent

Converge live EasyNet authoring surfaces on URA terminology by removing
retired URI labels from skill metadata, example resource labels, and the agent
identity guide's forbidden string-construction sample.

## Expected effect

- Architecture convergence: one routable address vocabulary remains visible on
  live authoring surfaces.
- Product acceleration: ability/page authors no longer copy URI-era field names
  into new resources.
- Public compatibility: resource values remain unchanged; only labels and field
  names move to URA.
