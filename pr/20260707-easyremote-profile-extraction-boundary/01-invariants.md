# Invariants

1. Axon remains the owner of URA and DescriptorRef grammar.
2. EasyNet-Cli daemon remains the owner of daemon ability carriers and host
   stream wire semantics.
3. Python SDK may expose facade helpers and DTOs, but consumers must not import
   SDK-internal direct runtime transport modules.
4. EasyRemote may keep product ergonomics such as decorators, `ComputeNode`,
   schema extraction, and TLS guidance.
5. EasyRemote must not keep generic publication, mission, admin/gateway,
   daemon lifecycle, raw host-stream codec, raw Invocation JSON, or raw
   addressing helpers.
6. The conformance gate must ignore comments, docstrings, tests, and fixtures
   while rejecting executable production code.
