# Invariants

- Canonical runtime-events roots expose stream lifecycle state only.
- Route catalog and subscription lowering names are provider-owned, not
  canonical model symbols.
- Product/provider route literals remain outside canonical Go and Python cores.
- The product-neutrality gate must reject route-lowering objects in canonical
  runtime roots.
- Removing the exported Go route-lowering types must be reflected by the live
  public API inventory validation.
