# Invariants

1. The aggregate `check-canonical-runtime-convergence-v2.sh` gate must pass
   against the current checkout.
2. SDK public API and parity manifests must be generated from current source
   revisions, not manually edited hashes.
3. Axon benchmark evidence must be regenerated by the benchmark harness when
   runtime source digests change.
4. Docker product evidence scripts must resolve required desktop/CI toolchains
   deterministically and must not depend on shell profile PATH.
5. Hardware media checks must be host-gated and skip-safe by default so CI and
   Docker gates remain deterministic.
6. Two-node product evidence must include provider-hosted user Agent lifecycle
   and a successful caller-to-provider-Agent canonical invocation with exactly
   one verified caller receipt chain.
7. Plugin sidecar templates may be exposed only for language/call-mode cells
   with a provider-scoped SDK helper that owns stdin/stdout frame parsing and
   result/error emission. Unary declarative exec helper coverage must not imply
   stream or bidi helper coverage. Templates must not hand-write sidecar JSON
   frames.
8. Bidi frame-0 terminality evidence is language-specific. A C ABI proof must
   exercise the C ABI boundary itself, reject before allocating an active bidi
   session, and must not rely on Go/Python wrapper evidence.
