# Architecture

## Boundary

`tests/scripts/test_check_architecture_convergence.sh` is gate infrastructure.
It does not define product behavior; it proves that the production architecture
gate distinguishes canonical source shape from retired compatibility shape.

## Refreshed Canonical Surfaces

- Ability routeability uses exact authority/mode control-plane records.
- Invocation dispatch callers route through callee-only target extraction.
- Local daemon loopback invocation binds an explicit subject.
- Local ability target subject policy is issued by the runtime target issuer.
- CLI identity projection is centralized through a shared display projector.
- Bidi receipt payload projection is centralized and fail-closed.
