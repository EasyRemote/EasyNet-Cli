# Java Swift Seam Conformance Reports Plan

## Goal

Promote Java and Swift Runtime Core seams from scaffold-only evidence to shared action-adapter report evidence without claiming provider-backed daemon transport support.

## Scope

- Add Java and Swift seam action-adapter reports for directly exercised Runtime Core cases.
- Mark the shared Runtime Core seam cases as required for Java and Swift.
- Extend the conformance report gate and scaffold guard to validate Java and Swift reports.
- Update status documentation so Java and Swift report support is represented as seam evidence, not provider-backed evidence.

## Non-Scope

- No Java or Swift daemon/C ABI provider.
- No profile coverage beyond directly exercised Runtime Core seam cases.
- No product cutover claim.
