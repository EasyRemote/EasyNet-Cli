# Invariants

- Frontend product-flow evidence must be `target_kind=both` for product completion.
- Runtime readiness must include both Hub API and product daemon readiness.
- UI flow evidence must be present before downstream host probes are treated as a product-flow pass.
- Browser/Tauri lifecycle evidence remains required and must back the end/cleanup lifecycle stage.
- Cross-device smoke must prove distinct caller/provider device URAs.
- Window and application paths must both prove decoded frame rendering and view-only input policy.
- Frontend flow summary is an aggregate of passed steps and child verifier artifacts; it does not redefine invocation, session, receipt, capture, input, or media semantics.
